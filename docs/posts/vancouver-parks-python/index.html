Distribution of Parks Across Vancouver

Author

Qibing He

Published

September 25, 2026

This post examines how public parks are distributed across Vancouver’s neighbourhoods. I will use Python to inspect the data, summarize the number of parks in each neighbourhood, and visualize the results.

Data: Parks, City of Vancouver Open Data Portal. The dataset is provided under the Open Government Licence – Vancouver.

Check and clean the data

Before counting parks by neighbourhood, I check the variables used in the analysis for missing values. Records without a neighbourhood or park area are excluded from the cleaned dataset.

analysis_columns = ["Name", "NeighbourhoodName", "Hectare"]

    parks[analysis_columns]
    .isna()
    .sum()

Parks by neighbourhood

I group the cleaned data by neighbourhood and count the number of parks in each area. The table below shows the ten neighbourhoods with the most parks.

park_counts = (
    parks_clean
    .groupby("NeighbourhoodName")
    .size()
    .reset_index(name="park_count")
    .sort_values("park_count", ascending=False)
)

Visualize the distribution

The following bar chart compares the number of public parks across Vancouver’s neighbourhoods.

park_chart = (
    alt.Chart(park_counts)
    .mark_bar(color="#2a9d8f")
    .encode(
        x=alt.X(
            "park_count:Q",
            title="Number of parks"
        ),
        y=alt.Y(
            "NeighbourhoodName:N",
            sort="-x",
            title="Neighbourhood"
        ),
        tooltip=[
            alt.Tooltip(
                "NeighbourhoodName:N",
                title="Neighbourhood"
            ),
            alt.Tooltip(
                "park_count:Q",
                title="Number of parks"
            )
        ]
    )
    .properties(
        width=650,
        height=500
    )
)

park_chart

Findings

The dataset contains 218 parks across 22 Vancouver neighbourhoods, and there are no missing values in the three variables used for this analysis. Downtown has the largest number of parks, with 23. Kitsilano and Hastings-Sunrise follow with 16 parks each. The results show that the number of parks is not evenly distributed across neighbourhoods, although this analysis counts parks and does not account for differences in park size.
